# Estoque QA Lab

Projeto prático de Quality Assurance aplicado a um módulo de controle de estoque.

## Objetivo

Criar um sistema simples, sem login, focado em validação funcional, testes de API, regras de negócio, banco de dados, evidências e automação de testes.

## Escopo inicial

- Dashboard de estoque
- Cadastro de produtos
- Cadastro de variações
- Consulta de estoque
- Movimentações de entrada, saída e ajuste
- Alertas de estoque mínimo
- Histórico de movimentações

## Tecnologias previstas

- Frontend: HTML, CSS e JavaScript
- Backend: Node.js e Express
- Banco de dados: SQLite
- Testes de API: Postman
- Automação: JavaScript
